# Slicer

[![Licence: MIT](https://img.shields.io/badge/Licence-MIT-yellow?style=flat)](LICENSE)
[![Open Slicer](https://img.shields.io/badge/Open-Slicer-orange?style=flat)](https://imbeyondidentity.github.io/Slicer/slicer.html)

English version: [README.md](README.md)

Снимает кадры с видео через равные
промежутки: каждые 2 секунды, каждые 5,
каждые 10 или с любым своим значением.

Два способа, результат одинаковый:

- **Браузерное приложение**
  (`slicer.html`): загружаешь видео,
  выбираешь настройки, скачиваешь кадры.
  Ничего не отправляется на сервер,
  всё работает на твоём устройстве.
- **Python CLI** (`slicer.py`): те же
  настройки из командной строки,
  через ffmpeg.

## Браузерное приложение

Открой страницу или просто запусти
`slicer.html` из папки.

1. Перетащи видео (или нажми и выбери).
2. Выбери интервал: 2 с, 5 с, 10 с или
   свой.
3. Выбери PNG или JPG и размер:
   оригинал, 1080p или 720p.
4. Нажми **Нарезать**.
5. Сними галочки с лишних кадров, затем
   скачай их по одному или одним ZIP.

Первый кадр берётся на 0:00, дальше по
одному каждые N секунд. Кадр в самом
конце видео не берётся.

Какие форматы видео откроются, зависит
от браузера. MP4 (H.264) работает везде.
Если файл не открывается, используй CLI.

## Python CLI

Нужны Python 3 и ffmpeg (вместе с
ffprobe). Больше ничего ставить не надо.

```
python3 slicer.py video.mp4
python3 slicer.py video.mp4 -e 2
python3 slicer.py video.mp4 -e 10 \
  -f jpg -q 85 --height 720 --zip
```

| Параметр | Что делает |
| --- | --- |
| `-e`, `--every` | Секунд между кадрами (по умолчанию 5, минимум 0.5) |
| `-f`, `--format` | `png` или `jpg` (по умолчанию `png`) |
| `-q`, `--quality` | Качество JPG, от 1 до 100 (по умолчанию 90) |
| `--height` | Максимальная высота, например 720 |
| `-o`, `--out` | Папка для кадров (по умолчанию `<имя>_slides`) |
| `--zip` | Дополнительно упаковать кадры в ZIP |

Кадры называются так:

```
video_0001_00m00s.png
video_0002_00m05s.png
video_0003_00m10s.png
```
